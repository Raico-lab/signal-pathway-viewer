# 制御遺伝子探索のテスト用データ

アプリの「制御遺伝子探索」タブの「CSV 読み込み」で読み込める、動作確認用の観測データです。

**実験で測った値ではありません。** 教科書・総説でよく知られた応答をもとに、遺伝子と増減の向きだけを例として並べたものです。
探索の点数の付け方を調整し、結果が妥当かを確かめるために使います。

| ファイル | 想定した状況 | 上位に来てほしい候補 |
|---|---|---|
| `rapamycin.csv` | ラパマイシン処理（TORC1 の阻害）。窒素分解代謝の遺伝子（GLN3・GAT1 の標的）が増え、リボソームタンパク質・リボソーム合成の遺伝子が減る。GLN3・ATG1 の活性が増え、SCH9 の活性が減る | TOR1（TORC1）の不活性化 |
| `heat_shock.csv` | 熱ショック。ストレス応答の遺伝子（MSN2/MSN4・HSF1 の標的）が増え、リボソームタンパク質の遺伝子が減る。MSN2・HSF1 の活性が増える | MSN2・MSN4・HSF1 の活性化、PKA（TPK1）・RAS2 の不活性化 |

## 列

| 列 | 値 |
|---|---|
| 遺伝子 | 遺伝子名 |
| 観測 | 発現 / 活性 |
| 変化 | 増 / 減 / 変化なし |

英語の列名・値（gene, expression / activity, up / down / none）でも読み込めます。

## 現在の結果（さかのぼる段数 3、2026-10-02 の並べ方: 転写因子の点数で増減の向きを使う・受け継ぐ掛け率 0.7）

- `rapamycin.csv`: TORC1 の不活性化が 1 位、GAT1 の活性化が 3 位、GLN3 の活性化が 4 位（どれも向きも正しい）。
  MSN2/4 は 11 位、PKA は 32 位。
- `heat_shock.csv`: HSF1 の活性化が 4 位、MSN2/4 が 5 位、PKA が 14 位（向きを使う前は MSN2/4 1 位・HSF1 21 位・PKA 9 位）。
  MSN2/4 が下がるのは、DB（YEASTRACT+ の記録）で MSN2・MSN4 がリボソームタンパク質の遺伝子（RPL3・RPL5・RPS3・RPS9B など）を
  「促進」する関係として登録されており、これらが減るという観測と向きが合わないため。データの側の事情。
- 比較: ランダムに選んだ 15 個の遺伝子に、でたらめに増減を付けたときは、補正後の確率が 0.05 未満の候補は出ない（3 回試して 0 個）。
