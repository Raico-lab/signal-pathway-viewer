# 依頼: シグナル伝達の関係の「作用の向き」を論文で確かめる（第 1 弾、100 本）

出芽酵母（*Saccharomyces cerevisiae*）のシグナル伝達の関係のうち、「A が B をリン酸化する」などの記録はあるものの、
**それによって B の働きが上がるのか下がるのか（作用の向き）** が分かっていないものが約 1,900 本あります。
これを論文で確かめて埋めたいので、手伝ってください。今回はそのうち、TOR などの中心の経路に近い 100 本です。

## 添付
- `signs_batch1.csv`: 対象の 100 本。左の 6 列はこちらで記入済み、右の 8 列を記入してください。

## 各行でしてほしいこと
1. 列 `biogrid_pmids` の論文（BioGRID がこの関係の根拠にしている論文）を読み、
   **上流（source_protein）の作用によって、下流（target_protein）の働きが上がるか下がるか** が書かれているか確かめてください。
   まず要旨、書かれていなければ本文（PubMed Central で読めるもの）を見てください。
2. `biogrid_pmids` の論文に書かれていなければ、ほかの出芽酵母の論文を探してもかまいません。
3. 書かれていれば、右の列を記入してください。**論文に書かれていなければ、`effect` は空欄のまま**にしてください。
   推測や一般論（「リン酸化は一般に活性化する」など）で埋めないでください。空欄は失敗ではなく、大事な結果です。

## 右の 8 列の書き方
| 列 | 書くこと |
|---|---|
| `effect` | `activate`（B の働きが上がる）、`inhibit`（下がる）、空欄（書かれていない・判断できない） |
| `direct` | `direct`（in vitro で直接修飾するなど直接の作用）、`indirect`（間接）、空欄（不明） |
| `pmids` | 判断に使った論文の PMID を **1 つ**。`biogrid_pmids` にないものでもよい |
| `paper_title` | その論文の題名を **PubMed に表示される英語の題名そのまま** |
| `quote` | 作用の向きが分かる**一文を論文からそのまま写す**（英語、言い換え・省略・つなぎ合わせをしない） |
| `quote_location` | `abstract` か `full text`（本文なら、章の名前も。例: `full text: Results`） |
| `condition` | 作用が条件つきなら、その条件と細胞周期の時期（例: `窒素飢餓`、`ラパマイシン`、`G1 期`）。なければ空欄。書き方は `request_core_pathways.md` の「条件の書き方」 |
| `note` | 判断の理由を日本語で短く（例: 「Ser 残基のリン酸化で核外に出て転写を止める」） |

## 判断の決まり
- **「働き」は下流のタンパク質そのものの働き** で判断してください。
  - 例: 転写因子がリン酸化されて核から出て働けなくなる → `inhibit`
  - 例: キナーゼが活性化ループをリン酸化されて活性が上がる → `activate`
  - 例: ユビキチン化されて分解される → `inhibit`（分解に向かう印であることが論文に書かれている場合）
  - 例: 抑制する側のタンパク質がリン酸化されて抑制をやめる → そのタンパク質の働きとしては `inhibit`
- 修飾が起こることだけ（「Pho85 が Pho81 をリン酸化した」だけ）で、働きの変化が書かれていなければ空欄です。
- 論文の中で、条件によって上がるとも下がるとも書かれている場合は、`effect` を空欄にし、`note` にその内容を書いてください。
- 関係そのものが論文で否定されている（実際には起こらない、別の遺伝子だった）と分かった場合は、`effect` を空欄にし、
  `note` を「誤り: 〜」で始めてください。
- 上流と下流が同じ複合体の構成要素で、複合体の中の受け渡しにすぎない場合は、`note` を「複合体内: 〜」で始めてください。
- 出芽酵母以外の生物の論文は使わないでください。

## 提出前に確かめてください
- `pmids` の論文を PubMed（`https://pubmed.ncbi.nlm.nih.gov/<PMID>/`）で開き、題名が `paper_title` と一致すること。
- `quote` が論文の文章とそのまま一致すること（記号・大文字小文字の違い程度は構いません）。

受け取った表は、こちらで自動で照合します（`tools/verify_literature.py`）。題名が一致しない行、`quote` が要旨にも
PubMed Central の本文にも見つからない行は取り込みません。PubMed Central で本文が公開されていない論文の本文から写した場合は、
照合できないので、`note` にその旨を書いてください（こちらで個別に確かめます）。

## 出力
- `signs_batch1.csv` と同じ 14 列・同じ行の順のまま、右の 8 列を埋めて返してください（行を消したり足したりしないでください）。
- ファイル名は `signs_batch1_done.csv` にしてください。
