# Pathways viewer for *Saccharomyces cerevisiae*

出芽酵母の遺伝子間の制御関係を可視化し、遺伝子どうしのつながり（経路）を探すデスクトップアプリです。
対象は TOR 経路に限らず全遺伝子です（同梱のサンプルデータは TOR 経路）。
（データベース・ネットワーク。シミュレーション・制御遺伝子探索・上流経路の予測は配布版に入れない。試作は `archive/`）

## 起動

- 配布版（インストーラー）:
  - Mac: `PathwaysViewer-<版>-mac.dmg` を開き、`PathwaysViewer.app` を「アプリケーション」へドラッグ。
    署名していないので、初回は Finder でアプリを右クリック >「開く」（macOS 15 以降は「システム設定 > プライバシーとセキュリティ」の「このまま開く」）。
  - Windows: `PathwaysViewer-<版>-windows-setup.exe` を実行（管理者権限は不要）。スタートメニューから起動。
    SmartScreen の警告が出たら「詳細情報 > 実行」。アンインストールは「設定 > アプリ」から（地図のデータは消えない）。
- 開発用: `python3.11 -m venv .venv && .venv/bin/pip install -r requirements.txt && .venv/bin/python main.py`

## データ（サーバーの版が正）

DB はサーバー（ブラウザ版の置き場 https://raico-lab.github.io/pathways-viewer/ 。`data/server.json` の `base_url`）の版が正です。
地図を軽く描くため、各 PC には写しを置いて使い、データベースタブは閲覧だけです（追加・編集・削除はしない）。

- 起動のたびに、サーバーの `manifest.json`（DB の版とハッシュ）と照らし、新しい版があれば尋ねずに入れ替えます（状態の帯に知らせる）。
  つながらないときは手元の写しで動きます。「ファイル > 最新データを確認」でいつでも確かめられます。
- 初回起動時は、アプリに同梱の DB（`data/tor_pathway.db`）を写しにします。同梱 DB が新しいアプリを入れたときも、サーバーから入れた写しがなければ同梱 DB に置き換えます。
- 情報源タブの論文・サイトの情報（`papers.json`・`sources.json`）もサーバーから取ります（取れなければ写しか同梱のもの）。
- 発現・リン酸化のデータ（`data/expression.db`）は地図の色分けに使うので、アプリに同梱したものを使います（アプリの更新で新しくなる）。
- 保存場所: Mac `~/Library/Application Support/PathwaysViewer/`、Windows `%APPDATA%\PathwaysViewer\`（「ファイル > データの保存フォルダを開く」）。表示の設定・登録もここに残ります。

### DB を直して届ける

1. `python tools/import_sources.py` で `data/tor_pathway.db` を作り直す（`raw_data/` の SGD・BioGRID と、`sample_data/` の精査済みデータを合わせる）。
   精査済みデータだけで作るときは `python tools/build_db.py proteins.csv interactions.csv`。
2. `python tools/publish_web.py --notes "変更点"` で公開する。ブラウザ版はすぐに、デスクトップ版は次の起動で新しい DB になります。

## CSV フォーマット

UTF-8 または Shift_JIS（Excel 保存）の CSV を読み込めます。書き出しは Excel で開ける UTF-8 (BOM 付き)。

**遺伝子** (`gene_name` 必須)

| 列 | 内容 |
|---|---|
| gene_name | 遺伝子名（表示名・照合キー） |
| standard_name | Systematic 名 |
| complex_category | 手作業のカテゴリ。2026-10-03 に手作業の複合体・区分（Upstream など）を外したので今は使わない（画面・CSV の書き出しには出さない） |
| protein_properties | ORF の確度（SGD の Verified / Uncharacterized / Dubious。取り込みで SGD の値を入れる） |
| description | 機能説明 |
| basal_activity | 上流入力がないときの活性 0〜1。空欄＝自動（シミュレーション用。今のアプリでは使わない。読み込みでは使うが、データベースの表・編集画面・CSV の書き出しには出さない） |

複合体は Complex Portal のものだけを使う（以前の手作業の枠 `groups.csv` と `data/complexes.csv` は 2026-10-03 に外した。`archive/` を参照）。
パラログ（役割が重なりうる遺伝子の組）は `tools/build_paralogs.py` が YGOB・Alliance の組を BioGRID の遺伝的相互作用と SGD の GO で裏付けて `data/paralogs.tsv` に書き、`tools/import_sources.py` がカテゴリ（出典「パラログ」）として入れる。地図では組ごとの色の二重線の枠で囲み、片方が地図にあればもう片方も加えて、上の段（注目している遺伝子があればその段）に並べる（複合体のような専用の段は作らない）。

**制御関係** (`source_protein`, `target_protein` 必須)

| 列 | 内容 |
|---|---|
| source_protein / target_protein | 上流 / 下流の遺伝子名（Systematic 名でも可）。未登録なら自動作成 |
| interaction_type | activation, inhibition, phosphorylation, dephosphorylation, transcription, localization, binding, other。酵素活性の修飾として ubiquitination, deubiquitination, acetylation, deacetylation, methylation, demethylation, sumoylation, desumoylation, neddylation, deneddylation, proteolysis, prenylation, glycosylation, enzymatic（修飾なし）も使える（これらの作用の向きの既定は none）。その他の語も可 |
| effect | 作用の向き activate / inhibit / none（空欄＝種類から自動。例: 抑制的なリン酸化は `phosphorylation` + `inhibit`） |
| threshold | 閾値 0〜1。空欄なら signal_threshold_rule の語から仮決め（High→0.7, Low→0.2, それ以外 0.5） |
| weight | 強度 0〜1（空欄＝1.0） |
| signal_threshold_rule | 閾値ルールのメモ。threshold・weight・signal_threshold_rule はシミュレーション用で、今のアプリでは使わない（読み込みでは使うが、データベースの表・編集画面・CSV の書き出しには出さない。`archive/README.md`） |
| evidence | 根拠・文献 |

サンプルは `sample_data/` を参照。データの集め方は [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md) を参照。

## 「ネットワーク」タブの使い方

初めて使う人向けの、画像付きの説明は [操作ガイド](docs/MANUAL.md) を参照。以下は細かい決まりのまとめ。

全体は描かず、注目する遺伝子の周辺だけを描きます（全遺伝子規模のデータでも軽く保つため）。

- 表示枠の上の検索欄に遺伝子名を入れ、候補を選ぶか Enter を押すと、検索欄の下に「拡張」「注目」の選択肢が出る。選ぶと検索欄は空になる。注目する遺伝子は常に 1 つで、別の遺伝子に注目すると切り替わる。上流・下流の段数は枠ごとに指定できる。
- 各表示枠の右上の「別ウィンドウで開く」で、表示枠を別ウィンドウに出す。枠が 1 つのときは今の内容を写した別ウィンドウを開き、2 つ以上のときはその枠を別ウィンドウに移す（メインの画面からは消す）。別ウィンドウの中でも検索・注目・拡張・詳細表示はでき、凡例・配置・色の設定はメインの地図と共通（左のタブは、メインの画面の操作中の枠に効く）。別ウィンドウは次回起動時には開かない。
- 各表示枠の右上の「⧉ 新しい枠」で表示枠を最大 4 つまで増やし、別々の遺伝子に注目できる。2 つ目は 1 つ目の右、3 つ目は 1 つ目の下、4 つ目は 2 つ目の下に置く（4 つで 2×2 の格子）。枠を閉じても、ほかの枠の横幅は変えない（列がなくなるときだけ、残りの枠が広がる）。青い枠が操作中の枠。各表示枠の検索窓の下に「配置」「色」（遺伝子の色）「線」（線の色）の選択肢がある（全表示枠に共通の設定で、どの枠で変えても全部の枠と別ウィンドウの地図にそろって反映する）。同じ行の右端の「PNG」「SVG」は、その表示枠の図全体（画面に見えていない部分も含む）を画像で保存する（PNG は 3 倍の解像度、SVG は拡大しても荒くならない）。
- 1 つの遺伝子の先が 30 を超える場合（転写因子の標的など）は 30 件だけ描き、残りは「+数字」で示す。凡例の「表示」欄の「+数」で表示の有無を切り替えられる（既定はオン）。
- 注目中の遺伝子（地図の中心）は大きく描き、橙の太い枠線で示す。クリックした遺伝子は緑（選択）、「拡張」した遺伝子は紫の枠線で示す（凡例の「強調表示」）。紫の枠線（上流・下流を追加した起点）は選択を外しても残り、別の遺伝子に注目し直すまで表示される。橙（注目の起点）と紫（追加の起点）をたどれば、今の表示がどこから広げた上流・下流かが分かる。
- 同じ遺伝子を続けてクリックすると、回数で動きが変わる。
  - 1 回目: 選択して右側に情報を表示する。
    遺伝子の説明（SGD の英文）は原文のまま表示する。
  - 選択中の遺伝子をもう一度クリックすると、遺伝子の下に「拡張」「注目」の選択肢が出る（Esc か他の場所のクリックで閉じる）。
  - 拡張（紫）: 遺伝子の位置と拡大率はそのままで、選んだ遺伝子の直接の上流・下流のうち表示されていないものを、それぞれの階層の段に追加する。下（上）に新しい段が増え、一番上（下）の段に注目中の遺伝子も選んだ遺伝子に線でつながるものもなければ、その段は隠して段数を増やしすぎない。
  - 注目（オレンジ）: その遺伝子を中心に表示し直す。注目する遺伝子 X が拡張（紫）か緑の選択なら、これまでの注目 F を X の役割に入れ替える（X が紫なら F が紫に、X が緑なら F が緑になる。紫を優先）。ほかの拡張・緑の選択はそのまま残し、拡張で加える遺伝子は新しい注目の範囲で決め直す（「再配置」と同じ計算）。詳細欄には新しい注目を出す。X がどちらでもないとき（検索欄から地図にない遺伝子に注目したときなど）は、拡張などを外して注目し直す。
  - 拡張では、追加した上流・下流も含めて図全体が枠に収まるよう表示範囲を合わせる。注目では、クリックした遺伝子とその直接の上流・下流が見えるよう表示範囲を合わせる（クリックしたものは画面の中央付近）。拡大率は 0.7〜1.3 倍の範囲にし、上流・下流が遠くて全部入らないときは、クリックした遺伝子を中心にして読める大きさを保つ。
  - 検索欄: 文字が入っている間は、名前の先頭が合う遺伝子、次に名前の途中に含む遺伝子を、検索欄の下に最大 50 個出し続ける（確定しても消えない。検索欄を空にすると消える）。候補をクリックするか Enter で「拡張」「注目」の吹き出しを候補の一覧の右に出す。↑↓ で候補を選び、Esc で検索欄を空にする。
  - 検索欄から選んだ「拡張」: 入力した遺伝子が地図にあれば、通常の拡張（上流・下流を 1 階層追加）。地図になければ、その遺伝子と、今の地図までの最短のつながり（向きは問わず 3 段まで。転写制御は使わない）の途中にある遺伝子だけを加える。経路が多いときは、多くの経路が通る遺伝子を優先して 15 個まで。紫の印が付き、凡例の × で加えたものをまとめて隠せる。
  - Shift を押しながらクリックすると、緑の選択を複数にできる（もう一度 Shift クリックで外す）。詳細パネルには最後に選んだものを表示し、つながりの強調は選んだものすべての周辺に付く。「⧉ 新しい枠」は緑のうち最後に選んだものに注目した枠を開く。
  - 左側の「経路」タブ: 操作中（青い枠）の表示枠で注目（橙）・拡張（紫）している遺伝子が一覧に並ぶ。チェックした遺伝子どうしがどの経路でどう関わるかを、選んだ表示経路・段数で一覧にする。地図では、チェックした遺伝子だけを目立たせ、経路の線と途中の遺伝子（共通の制御因子・標的も）は一覧で選ぶまで描かない。表示経路を切り替えても地図の配置は動かない（ボタンはなく、チェック・表示経路・段数・基準の遺伝子を変えるたびに反映する。計算は `tor_app/relation_paths.py`）。注目・拡張から外した遺伝子のチェックは外れる。見方を「OFF」にすると、加えた遺伝子を消して普段の地図に戻る。対象の遺伝子の一覧の下の「すべて選択」で一覧の遺伝子をすべてチェックし、「すべて解除」でチェックをすべて外す。
    - 経路の段数: 1〜3（既定 1）。段数が**ちょうど**その数の経路だけを出す（1 なら直接の関係）。経路の途中で同じ遺伝子を 2 度通らない。
    - 複合体（地図の点線の枠: TORC1・PKA など）は 1 つの単位として扱い、複合体の中の受け渡しは段数に数えない。
    - 経路は転写制御も含めてたどる（共通の転写因子 A ← MSN2 → B なども見つかる。凡例で隠した関係・「作用が分かっている関係のみ」の設定は反映する）。
    - 経路の一覧は、選んだ表示経路のすぐ下に出る。3 段にまとめる: 上流（経路の左端）ごと（例: 「TORC1 から（12 本）」）→ その下に上流と行き先の組ごと（例: 「TORC1 … MAF1（2 本）」）→ その下に経路が 1 行ずつ（例: `TORC1 –P→ SCH9 –P◇ MAF1`。→ 促進、⊣ 抑制、◇ 作用不明、← ⊢ は右から左への矢印、P・Tx などは関係の種類）。行は上流を左に書く。
    - 並べ方: 上流のまとめは、上流の遺伝子の階層（ネットワーク全体で決めた上下の順。同じ階層なら地図の配置の番号）の順。その中の組は行き先（右端）の同じ順で、組の中の経路は、途中の遺伝子の関係の数（ハブ）が少ない経路を先にする。根拠の確かさは並べ方に使わない。一覧の本数・共通の制御因子の数に上限はない（計算が終わらなくなるのを防ぐため、同じ両端の経路は 5,000 本に達したら数えるのをやめ、「5000 本以上」と出す）。
    - 一覧の経路を選ぶと、その経路を地図で強調する（上流のまとめや組を選ぶと、その中の経路すべて。Ctrl / ⌘ で複数選べる）。経路の遺伝子が地図になければ一時的に加える。背景をクリックすると戻る。
    - 表示中に地図の遺伝子（または複合体の枠）をクリックすると、一覧をその遺伝子を通る経路だけに絞る（線は描かない）。背景をクリックすると絞り込みを外す。緑の選択・詳細の表示は普段どおり。
    - 基準の遺伝子: チェックした遺伝子から 1 つ選べる（「（なし）」も選べる）。選ぶと、基準の遺伝子が端にある経路だけを一覧にする。基準の遺伝子には濃い青緑の縁取りを付ける。
    - 一覧で選んだ経路の途中の遺伝子は、地図になければ一時的に加える（選択を外すか背景をクリックすると消える）。
    - 「強調中の遺伝子を新しい枠で開く」: いま経路タブで強調している遺伝子（一覧で選んで描いている経路。選んでいなければチェックした遺伝子）だけを、新しい表示枠に描く（表示枠の数の上限 4 つに数える）。開いたときの遺伝子の組と経路の強調を保ち、あとから「経路」タブの設定を変えても変わらない（経路の設定はこの枠には当てはめない）。枠の中でもクリックでの詳細表示・拡張・凡例のチェックは使える。「再配置」は、拡張などで加えた遺伝子を外し、開いたときの遺伝子の組に戻して配置し直す。注目・段数・検索はこの枠では使わない。遺伝子は名前で覚えるので、次回起動時も同じ組で開く。
    - 表示経路:
      - OFF: 経路を表示しない（普段の地図）
      - すべての経路: チェックした遺伝子どうしを、指定の段数で結ぶすべての経路（各段の矢印の向きは問わない。共通の標的、つまり A → X ← B の X を経由する経路も含む）。左は階層の上の端
      - 矢印の向きにたどれる経路: チェックした遺伝子から、別のチェックした遺伝子へ矢印の向きにたどれる経路（途中はどの遺伝子でもよい。A → X → C も出る）
      - すべてを制御している遺伝子: チェックした遺伝子すべてに、ちょうど指定の段数で届く上流の遺伝子（共通の制御因子。階層の上から順に）と、そこからの経路
      - すべてから制御を受けている遺伝子: 同じく下流の共通の標的と、そこへの経路
      - 基準の遺伝子へ作用している経路 / 基準の遺伝子から作用している経路: ほかのチェックした遺伝子から基準の遺伝子へ（基準の遺伝子から、ほかへ）、矢印の向きにたどれる経路
  - 左側の「登録」タブ: よく見る表示の設定に名前を付けて登録し、一覧から呼び出せる。登録する項目はチェックで選ぶ: 注目（注目・上流/下流の段数）、拡張（紫と、それで加えた遺伝子・隠した段）、TFs（左の TFs 一覧でチェックした転写因子）、緑の選択、経路（チェックした遺伝子・表示経路・経路の段数・基準の遺伝子）、凡例（隠す役割・制御の種類・作用と「表示」欄）。一覧で選ぶと内容を表示し、「呼び出す」（ダブルクリックでも可）で、登録した項目だけを操作中の表示枠に当てはめる（凡例は全表示枠に共通）。登録していない項目は今のまま。ただし注目だけを呼び出すと、拡張と TFs は外れる（別の遺伝子に注目したときと同じ）。呼び出した TFs のうち、その注目・拡張の TFs 一覧にないものは表示しない。経路のチェックは、呼び出した地図にある遺伝子だけ。同じ名前で登録すると確認のうえ上書きする。遺伝子は名前で保存し、DB にない遺伝子は無視する。保存先はこの PC の `saved_views.json`。
  - 凡例の「強調表示」に、いま緑・紫・橙の印が付いている遺伝子名を並べる。名前の横の × で個別に解除できる（紫を外すと、その拡張で追加した遺伝子を隠し直し、追加したものから更に広げた紫も一緒に外して、図全体が見えるよう表示範囲を合わせ直す。橙の注目は常に 1 つなので外せない）。
  - 各表示枠の右上の「⧉ 新しい枠」で、新しい表示枠を開く。緑で選択中の遺伝子があればそれ（複数なら最後に選んだもの）に、なければ最後に紫にしたもの、それもなければ注目中のものに注目する。
  - 拡張・段数の変更・注目の変更で、描く線が 200 本を超えて増えるときは（150 本を超えると線を引く仕組みが重なりを許し始める）、線の計算を始める前に確認を出す。「キャンセル」で変更前の表示に戻る（基準は `tor_app/ui/graph_pane.py` の `WARN_EDGES`）。
  - 別の遺伝子・線・背景をクリックすると数え直す。追加や段を隠した操作も ◀ で戻せる。
- 上流・下流の段数を続けて変えたときは、0.25 秒待ってから最後の値だけ計算する。表示を増やしすぎて重くなっても、すぐに段数を変えれば、前の表示の残りの処理（アニメーション・線の経路計算）は打ち切られる（すでに始まった配置の計算だけは終わるまで待つ）。
- 遺伝子はドラッグで動かせない（配置は自動で決める）。背景のドラッグで表示範囲を動かし、ホイールやピンチで拡大・縮小する。
- 注目を移すと、前の表示にもあった遺伝子は新しい位置へ動き（約 0.65 秒）、新しく現れたものはその場で浮かび上がる。線は移動が終わってから引き直す。
- 配置の選択肢（各表示枠の検索窓の下）を変えると、すぐに全表示枠へ反映する。配置「階層（縦）」では、遺伝子を上流ほど上の段に並べる。段の上下の順序は全体の階層に従い、段は表示中の遺伝子の間だけで詰める（関係のある階層どうしは必ず 1 段以上離す）。段の見出し（階層の番号）は表示しない。段の中の左右は「配置の番号」の小さい順に並べる。配置の番号は全遺伝子にネットワーク全体で一度だけ振る固定の番号で（階層の上から順に、同じ階層の中では上流・下流の相手の位置の平均で線の交差が少なくなる順。並びが同じなら名前順）、どのマップでも「A は B の左」の関係が変わらない。複合体は構成要素をひとまとまりにし、構成要素の番号の平均の位置に置く。遺伝子が増減するたびにこのルールで並べ直すので、同じ遺伝子の組なら操作の順序によらず同じ配置になる（「格子」は番号順。「同心円」はつながりの多い遺伝子ほど内側の輪に置き、輪の大きさを実際の箱の大きさで決めて詰める）。番号は遺伝子の詳細欄に表示する。1 行に並べるのは 10 個までで、超えると同じ段の中で折り返す（複合体の枠は 2 行に分けない）。行と行の間隔は、箱が重ならない最小の間隔に、その間を横切る線の本数ぶんの通り道（遺伝子・線が多いほど細く、上限あり）を足して決める。段の中の遺伝子どうしの隙間も、遺伝子が多いほど狭くする（余白を減らすため、線の重なりは許す）。段の変わり目は折り返しの行間より少し広く空けるので、折り返しと階層の違いは行間で見分けられる。図が横幅の 1.25 倍より縦に長くなるときは、重ならない範囲で行間を詰めて正方形に近づける。「階層（横）」では列になる。色分けを「役割」にすると、役割（色）と上下の位置を同時に見られる。
- 階層の決め方（制御する側を上に）:
  - 複合体の構成要素と、直接互いに作用し合う組（A⇄B）は同じ階層にする。
  - それ以外の循環は、上向きになる関係ができるだけ少なくなるよう一部の関係を例外にして断つ。まず作用の向きが分かっている関係だけで上下の順序を決め、向き不明の関係はその順序と矛盾しないものだけ使う（向きの分かる関係を優先）。
  - 実データでは全関係 38 階層（下から上へ向く関係は約 3%）、作用既知のみ 21 階層（約 2%）。
  - そのため向き不明の関係も、矢印のない線でつなぐだけで、ほぼ上から下へ反応が進むと読める。
- 凡例の「作用の向き」「制御の種類」「役割」の各行の左にあるチェックボックスで、表示するかを選べる（どの表示枠の凡例で切り替えても全表示枠に反映、次回起動時も引き継ぐ。凡例の各欄（作用・修飾・制御の種類・役割・役割で絞り込み・表示）の見出しの左のチェックボックスで、その欄の項目をまとめて表示・非表示にする。欄の項目がすべてチェックされているときだけ見出しのチェックが付き、どれか外れていれば外れる）。色分けが「役割」以外のときも、凡例の「役割で絞り込み」欄で切り替えられる。
  - 役割を外す → その遺伝子と、つながる線を隠す。
  - 制御の種類・作用の向きを外す → その線と、表示中の線が 1 本も残らなくなった遺伝子を隠す（注目中の遺伝子は残す）。
  - 隠しても線は引き直さない（残った線は隠す前の形のまま）。表示に戻した線も、その形が使えればそのまま戻す。
  - 隠しても配置は詰めない。「再配置」で、表示中のものだけで配置し直して隙間を詰める。表示に戻した遺伝子が他と重なるときだけ自動で配置し直す。
  - 「再配置」は配置だけでなく、表示する遺伝子も 注目・拡張（紫）・段数・凡例のチェック から決め直す（範囲外の遺伝子は消す。凡例で隠した種類・作用・役割の関係はたどらない）。同じ設定なら常に同じ図になる。
- 色分けは 2 種類。どれも遺伝子ごとに決まった色で、注目する遺伝子を変えても同じ遺伝子は同じ色になる。
  - 役割（既定）: SGD の機能説明の最初の一文から推定した役割（キナーゼ・ホスファターゼ・転写制御因子・GTPase・輸送体・リボソーム/翻訳・代謝などの酵素・複合体の構成要素・機能不明など）。自動分類なので目安。
  - 階層: ネットワーク全体での位置。制御する側ができるだけ制御される側より上の階層に来るように決める（下の「階層の決め方」）。全体の階層数に合わせて青（上流）→赤紫（下流）に塗り分ける。
- 線は常に遺伝子を避ける直角の折れ線で描き、線どうしは重ねない（交差はする）。配置の後に引き直す。線の始点・終点は、他の線がなければ遺伝子の辺の中点、他の線があるときはなるべく中央寄りにする。経路をすべて計算し終えてから描くので、途中の線は表示されない（計算中は前の線のまま、新しい線は計算が終わるまで隠す）。線が 150 本を超える密な図では速さを優先し、避けきれない重なりが出ることがある（線が 200 本を超えるときだけ、画面上部に案内を出す）。つながりの多い遺伝子は箱を横に広げて出入り口を確保する。
- 既定では、拡大・縮小で遺伝子は消えない。凡例の「表示」欄の「縮小したら下流の枝先を省略」をオンにすると、図全体を枠に収めた状態からさらに縮小したときに下流の枝先から省略する（先が省略中の遺伝子は点線の枠）。
- 凡例で制御の種類・作用を隠したとき、表示中の線がなくなった遺伝子は隠す。ただし、注目・拡張の起点・拡張や検索で加えたもの・左の一覧で選んだ TFs は残す。
- 各表示枠の ◀ ▶ で、その枠の直前の表示に戻れる（Mac: ⌘[ / ⌘]、Windows: Alt+← / Alt+→ は操作中の枠に効く）。
- 起動時は前回の表示枠の数・配置の方式・色分けと、表示枠ごとの注目・段数・拡張（紫）とそれで加えた遺伝子・「経路」などで加えた遺伝子・TFs のチェック・緑の選択を復元する。緑の選択は、最後に選んだ遺伝子の詳細も右側に表示する（初回や、前回の遺伝子が DB にない場合は TOR1 を上流・下流 1 段で表示）。

### 線の見方

- 線の色と線上の記号で修飾・制御の種類を表す（リン酸化＝橙・P、脱リン酸化＝紫・-P、ユビキチン化＝ピンク・Ub、転写制御＝青・Tx など）。
- ツールバーの「線の色」で「作用」を選ぶと、線の色を作用ごと（促進＝赤、抑制＝青、作用不明＝灰、結合＝薄い灰。作用の色はアプリ全体でこの色）に切り替えられる。このとき修飾の種類は線上の記号（凡例の「表示」欄の「種類記号」）で確認する。
  仕組みは不明で作用だけ分かっている関係は濃い灰色・「—」。
- 終点（制御される側）の印の形で作用を表す。印のある端が制御される側（向き）。
  - 塗りの三角: 促進
  - T 字: 抑制
  - 白抜きの菱形（実線）: 作用不明（向きはある。BioGRID の酵素-基質など）
  - 印なし（破線）: 向きのない関係（結合）
- 転写制御（Tx）は YEASTRACT+ の文献で裏付けのある関係（DNA への結合と発現変化の両方）を含む（約 4.4 万本）。促進・抑制は YEASTRACT+ の発現変化の報告から付けており（促進 約 1.6 万・抑制 約 1.2 万）、両方の報告がある組は作用不明のまま。ほかの相互作用とは別扱い。上流・下流のたどり方・「+数」・階層には使わない（表示はする）。注目（オレンジ）・拡張（紫）した遺伝子ごとに、それを制御する転写因子（TFs）を左側の一覧にチェックボックス付きでまとめて並べる（遺伝子ごとの欄は見出しで開閉でき、最初は閉じている。既定はすべて外れている。作用が分かっているもの・他の関係も持つものが上）。チェックすると、その表示枠のマップの一番上の専用の段に表示する。複数の遺伝子の TFs になっている転写因子には ⇄ を付け、チェックは欄の間で連動する。紫・オレンジを外すと、その遺伝子の欄と、他の欄にない TFs は地図からも消える。拡張（紫）でも転写制御はたどらない。凡例でチェックを入れると、表示中の遺伝子どうしの転写制御の線だけが現れる。
- 凡例の「修飾・制御の種類」には DB にあるすべての種類を並べる（今の表示に出ていない種類は薄く表示）。表示する前にチェックボックスで絞り込める。
- 線上の文字（種類の記号）は既定では表示しない（凡例の「表示」欄の「種類記号」で表示できる）。
- 凡例は「強調表示」「作用」「修飾・制御の種類」「役割」「表示」などの欄に分かれ、見出しをクリックすると欄ごとに閉じられる（開閉の状態はこの PC に覚えておく）。
- 種類 activation / inhibition は「仕組み（修飾など）は不明で、促進・抑制の作用だけ分かっている関係」。
  凡例の種類の欄では「機構不明」の 1 行（促進・抑制の作用だけが分かっている関係）にまとめ、リン酸化などの仕組みとは分けて扱う。

## 条件（関係が働く条件）

関係ごとに、働く条件を DB の `interactions.conditions` に持つ（条件のキーを `;` でつなぐ。記録がなければ空）。
条件の一覧は `data/conditions.csv`。YEASTRACT+ の環境条件の群・小群（14 群・69 小群）に合わせ、文献にだけ出る小胞体ストレスを足した
70 種類（キー・群・表示名・YEASTRACT+ の群/小群・文献の書き方を当てはめる言葉）。読み書きは `tor_app/conditions.py`。

- 集め方（`tools/import_sources.py` の最後）: YEASTRACT+ の小群ごとの表（`raw_data/YEASTRACT/conditions/`。
  `tools/fetch_yeastract_conditions.py` で自動で取る）をその組の転写制御に、文献の CSV（`sample_data/literature/`）の
  `condition` 列をその組のすべての関係に付ける。当てはまらない書き方は `docs/source_conflicts.tsv` に出す。
  YEASTRACT+ の条件は「その条件で報告がある」という意味で、その条件のときだけ働くとは限らない。
- 画面: 線の説明に「条件」を出す。左の「条件」タブに、DB の関係に付いている条件を群ごと（開閉できる）にチェックボックスで並べる
  （既定はすべてオン）。外した条件があると、チェックした条件を持つ線とその両端の遺伝子だけを目立たせ、ほかは薄くする。
  「条件の記録なし」も選択肢の 1 つ。選択は次回起動時も引き継ぐ。

## 説明欄の履歴

右側の説明欄の上の ◀ ▶ で、表示した遺伝子・線・複合体の履歴（50 件まで）をたどる。戻ったときは地図の選択も合わせる（遺伝子は緑の選択、線は強調。省く線でも見せる）。新しく表示すると、進む側の履歴は消える。

## 転写因子どうしの線

転写因子どうしの転写制御の線は、地図に描かない（転写因子は互いを制御し合う記録が多く、TFs を並べると線で埋まるため）。
どちらかが注目・拡張（紫）している遺伝子の線と、「経路」タブの経路の線は描く。緑で選んでいる遺伝子は、地図にある相手との線をすべて描く（選択を外すと隠す。遺伝子の箱の幅は、省いている線も含めて数える）。「経路」タブの経路の計算では使う。
遺伝子をクリックすると、地図にある転写因子との線を省いていれば、その本数と相手を説明欄に出す。
（関係の数で「一般的な遺伝子」の線を隠す閾値は、2026-10-02 に試して外した。）

## 配布用ビルド

アプリが読むデータ（`data/` のうち spec の `DATA_FILES` に挙げたもの）だけを同梱する。版は環境変数 `PATHWAYS_VERSION` で渡す。

- Mac: `PATHWAYS_VERSION=1.0.0 .venv/bin/python -m PyInstaller --noconfirm PathwaysViewer.spec` → `./installer/mac/make_dmg.sh 1.0.0` → `dist/PathwaysViewer-1.0.0-mac.dmg`
- Windows: Windows PC 上で `build_windows.bat 1.0.0` → `dist\PathwaysViewer-1.0.0-windows-setup.exe`（[Inno Setup 6](https://jrsoftware.org/isdl.php) が必要。設定は `installer/windows/PathwaysViewer.iss`）
- GitHub に置けば `.github/workflows/build.yml` で両 OS のインストーラーを自動ビルド（Actions の成果物からダウンロード）。`v1.0.0` のようなタグをプッシュすると Releases にも載る。
- Mac 版はビルドした PC の CPU 向け（GitHub の macos-latest は Apple シリコン）。

## ブラウザ版（GitHub Pages）

- 公開先: `webapp/site.json` の `repo`（公開用のリポジトリ。ソースは置かず、書き出したものだけ）の GitHub Pages
- 手元で試す: `.venv/bin/python tools/build_web.py --serve` → http://localhost:8765/
- 公開する: `.venv/bin/python tools/publish_web.py`（`--desktop` を付けると、Actions の build の最新の成功した成果物を、上部の「デスクトップアプリ」タブからダウンロードできるインストーラーとして Releases に置き換える）
- 表示の設定・登録は、見ている人のブラウザ（IndexedDB）にだけ残る。DB は開くたびに公開中の版を使う（サーバーとの照らし合わせはしない。`data/server.json` は書き出しで空にする）
- 互換層に足りない Qt の機能に当たったら、`webapp/shim/PyQt6/` に足す（`tor_app/ui/` をブラウザ向けに変えない）。ブラウザでは画面を止めて待てないので、ダイアログは `exec()` でなく `open()` と `accepted` で受ける
- `tools/publish_web.py` は、デスクトップ版が照らす `manifest.json`（DB の版・ハッシュ・取り先 `data/tor_pathway.db.gz`）と `papers.json`・`sources.json` も一番上に置く
- 起動の時間（手元の Chrome）: 初回 約 8 秒＋ダウンロード（約 18 MB と Pyodide）、2 回目から約 6 秒
